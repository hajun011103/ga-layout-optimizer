# 목적함수 항 카탈로그

전체 목적함수는 `F = Σ wₖ · (항ₖ)` 이다.
다목적(`--mode nsga`)으로 갈 경우 **w₁·w₂·w₃ 를 가중합에서 빼내 NSGA 의 세 목적으로
두고, w₄~w₉ 는 제약/페널티로 남긴다** — HPR1000 보조건물 연구의 구성과 동일하다
(면적 −11.44%, RZDI −30.01%, 배관비 −34.92%).

구현: `engine/ga_core.py` `Solution.evaluate()`. 항 이름이 곧 IR `weights` 의 키다.

---

## 항

| 키 | 수식 | 무엇을 재는가 | 근거 |
|---|---|---|---|
| `volume` | `w₁ · W·D·H` | 건물 체적. 콘크리트·철근 물량, 굴착량, 시공 공기로 직결. **면적이 아니라 체적을 권장** — 층수 결정과 맞물리기 때문이다 | Patsiatzis & Papageorgiou 2002 |
| `area` | `w₁' · W·D` | 건축면적. 체적 대신 쓰고 싶을 때만 (기본 가중치 0) | 〃 |
| `link` | `w₂ · Σ C_ij(\|Δx\|+\|Δy\|+λ\|Δz\|)` | 배관·케이블·덕트 물량. 맨해튼(직교) 거리가 표준 대리모형. λ 는 수직 이동의 상대 비용(관통부·서포트·양정) — **3~5 권장** | Wrigley 2019 · Bae 2014 |
| `zone` | `w₃ · Σ_z (1/\|z\|) Σ_{i∈z} ‖p_i − p̄_z‖` | 방사선구역 분산(RZDI 계열). 같은 구역 기기가 흩어질수록 차폐벽 면적·오염관리 구역·출입통제 동선이 늘어난다. 순수 기하량이라 싸면서 차폐비용의 좋은 대리지표 | Ann. Nucl. Energy 2026 (HPR1000) |
| `sep` / `sep_soft` | `w₄ · Σ max(0, d_min − gap_ij)` | 물리적 분리 위반. **중심 간 거리가 아니라 외곽 간 간극(gap)** 으로 잰다 — 큰 기기의 중심거리는 실제 이격을 과대평가한다 | App. R / RG 1.189 |
| `exterior` | `w₅ · Σ_{i∈B_ext} dist(i, ∂Ω)` | 외벽 접면 요구. EDG 급배기, 공조 외기취입, 해수펌프, 반출입 해치, RCA 출입통제. **이 항이 없으면 최적화기가 체적을 줄이려고 이들을 건물 한가운데로 밀어 넣는다** | — |
| `crane` | `w₆ · Σ_{i∈B_cr} out(i, Ω_crane)` | 크레인 커버리지. SFP, 고체폐기물 저장, 반출입 해치 | SRP 9.1.5 |
| `aspect` | `w₇ · max(0, max(W,D)/min(W,D) − ρ)` | 외피 형상비. 면적만 최소화하면 길고 얇은 건물이 나오는데 내진 거동·기초 공사·구조 격자 관점에서 받아들일 수 없다. ρ ≈ 1.5~2.0 | — |
| `ecc` | `w₈ · ‖c_mass − c_geom‖` | 질량 편심. 질량중심과 강성중심이 어긋나면 지진 시 비틀림 응답이 커진다 | Bae et al. 2014 (FPSO, CoG 1 m² 이내) |
| `elev` | `w₉ · Σ max(0, z_j + Δ_ij − z_i)` | **SMR 고유** 중력구동 표고 순서. 피동안전계통은 중력 수두로 동작하므로 재장전수탱크·피동냉각수탱크가 주입지점보다 규정 높이 이상 위에 있어야 한다. 기존 대형원전 배치 문헌에 없는 제약이며 층 배정을 강하게 구속한다 | — |
| `envelope` | `max(0, W−W_max) + max(0, D−D_max)` | 부지/구조 한계 초과 | — |
| `fixed` | `Σ dist(center_i, fixed_xy_i)` | 좌표 고정(원자로·격납건물) 위반 | — |
| `constraint.<ID>` | 제약 라이브러리별 | [constraint-library.md](constraint-library.md) 참조 | — |

`sep`, `exterior`, `crane`, `elev`, `envelope`, `fixed` 와 hard 제약은
**최종해에서 0 이어야 한다** (`ga_core.HARD_TERMS`).

## ★ 가중치를 어떻게 정할 것인가

세 가지 방식이 있고, 이 도구에는 **세 번째**를 권한다.

| 방식 | 장점 | 한계 |
|---|---|---|
| 단위 통일 (모든 항을 원(₩)으로 환산) | 가중치 논쟁이 없어짐 | 차폐비·안전여유는 화폐화가 어렵거나 왜곡됨 |
| 정규화 가중합 | 구현 단순 | 가중치가 곧 설계 판단인데 근거를 대기 어려움 |
| **Pareto + 인간 선택** (`--mode nsga`) | 가중치를 미리 정할 필요가 없음. 설계자가 트레이드오프를 보고 결정 → **책임소재 명확** | 계산량 증가, 결과 제시 UI 필요 |

Autodesk Project Discover(2017)가 6개 목적으로 1만 개 안을 생성해 Pareto 집합을
설계자에게 제시한 방식이 이 워크플로의 원형이다.

### 함정 — 반드시 알아야 할 것

**hard 제약의 가중치가 목적항 대비 충분히 크지 않으면, 최적화기는 "위반 페널티를
내고 체적을 줄이는" 해를 정상적인 최적해로 반환한다.**
프로토타입에서 실제로 발생했다 — 크레인 커버리지 가중치를 10배 올리기 전까지
최적해가 크레인 베이를 **1.9 m** 벗어나 있었다. 최종해에서도 방사선관리구역
출입통제가 외벽에서 **0.10 m** 떠 있었다. **둘 다 도면상 정상으로 보인다.**

`validate_spec.py` 가 이것을 자동 점검한다. 비교는 총량이 아니라 **한계이득**으로 한다.

```
1 m 를 양보해서 얻는 이득  ref_m  = w_volume·max(D·H, W·H) + w_area·max(W,D)
                                    + w_link·max_i Σ_j c_ij
1 m² 를 양보해서 얻는 이득 ref_m2 = w_volume·H + w_area
```

hard 페널티 가중치가 `ref × 10` 미만이면 **WARN** 이 뜬다.
크레인 베이처럼 **경계가 외피 비율로 정의되어 최적화 중 함께 움직이는** 항은
그보다 더 큰 가중치가 필요하다(예제에서는 하한의 약 7배).

## 층수를 결정변수로 둘 것 — 의사결정 근거로 직접 쓰인다

`--sweep-floors 1-6` 이 층수-비용 트레이드오프 곡선을 만든다.

> Ejeh 2019 민감도: 요소플랜트 **1층 260,942 → 2층 167,299 → 3층 149,498 →
> 4층 117,431 (−55.0%)**. CDU **1층 1,112,095 → 7층 592,322 (−46.7%)**.

**층수를 고정하면 이 절반가량의 개선 여지가 통째로 사라진다.**

주의: SMR 은 부호를 뒤집어야 하는 구간이 있다. 일반 플랜트에서 수직 이동은
펌핑비(수평의 약 10배)지만, **피동 중력구동 계통에서 표고 확보는 비용이 아니라
편익**이다. `link.vertical_factor` 는 비용이고 `elev` 항이 편익 쪽이다 — 두 항을
같이 켜 두어야 균형이 맞는다.

## 원문에서 확인한 정식화 세부 — 그대로 가져올 것들

| 항목 | 내용 | 출처 |
|---|---|---|
| 안전거리는 체비셰프, 배관은 직교 | 연결배관은 rectilinear(맨해튼), 안전이격은 `TD_ij = max(XD, YD, VD)`. 유클리드 근사가 좋으면서 선형화 가능. 원저자가 유클리드 대비 위험지수가 동일함을 검증 | Ejeh 2021 |
| 안전을 비용으로 넣으면 총비용이 내려간다 | 아크릴산 플랜트 11기기 4층. 도미노 확산 기대손실을 비용항으로 내부화 → 총비용 789,159 → **667,113 (−15.5%)**, 도미노 확산비용 171,540 → **12,613 (−92.6%)**. "안전을 하드 제약으로만 걸면 오히려 비싸진다"는 정량 근거 | Ejeh 2021 |
| 유지보수 공간의 실용적 규칙 | 기기 치수의 **30%** 를 유지보수 공간으로 자동 부여. FPSO 는 기기 간 **1.9 m** 통행폭 + 갑판 가장자리 2 m. 본 엔진의 `clearance` 팽창 방식이 이것에 해당 | Lee 2015 · Bae 2014 |
| 공지(free area) 제약 | 1층 면적의 50% 작업공간, 최상층 60% 비상공간. **이런 제약이 없으면 최적화기가 층을 가득 채운다** | Ejeh 2019 |
| 대칭성 제거 / 정수컷 | 거울상 해를 배제하면 CDU 17기기에서 CPU 1,678초 → **132초(약 11배)**. MILP 로 갈 경우 필수 | Ejeh 2019 |
| 거리를 직선이 아니라 실제 동선으로 | 군함 구획배치에서 `d_ij` 를 Dijkstra 통로 경유 보행거리로. 원전의 RCA 동선·ALARA 피폭선량 평가에 직접 대응 | ICED 2021 |
| 최적보다 실무안이 채택된 사례 | 기관실 위치를 고정한 안(F=17,242)이 자유 최적안(F=17,198)보다 목적함수는 나쁘지만 실무적으로 타당하다고 판단되어 채택 — **최적화 결과를 그대로 쓰는 것이 아니다** | ICED 2021 |
